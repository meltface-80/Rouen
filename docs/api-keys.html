API keys

All free, all optional — but they significantly improve artwork and label coverage, and Last.fm adds similar artists and albums to every album page. Paste each one into the app under ☰ → Settings → Setup → API Keys, then Save — the box shows a ✓ once the service has accepted the key. Label logos also need Settings → Setup → Record labels switched on.

Free

FanArt.tv

Record-label logos for labels that have a MusicBrainz MBID, and the wall display's artist photos.

  1. Register (or sign in) at fanart.tv/get-an-api-key and request a personal API key
  2. Follow the on-screen prompts — the key is shown on that page once you're logged in
  3. Copy the key
  4. In the app: ☰ → Settings → Setup → API Keys → paste into FanArt.tv key → Save (a ✓ shows it works)
Free

Discogs

Finds label names that iTunes and MusicBrainz miss, and fetches label logos.

  1. Sign in (or register) at discogs.com
  2. Settings → Developers → Generate new token
  3. Copy the token
  4. In the app: ☰ → Settings → Setup → API Keys → paste into Discogs token → Save (a ✓ shows it works)
Free

Last.fm

Similar artists and similar albums at the foot of every album page — opened in the app when they are in your library, on Last.fm when not. Read-only — nothing is scrobbled.

  1. Sign in at last.fm, or sign up free — any Last.fm account will do
  2. Open last.fm/api/account/create (the Get an API account link on last.fm/api)
  3. Fill in your email, an application name (e.g. Rouen) and a short description; the callback URL and homepage can be left empty
  4. Submit, then copy the API key — not the shared secret, which isn't needed
  5. In the app: ☰ → Settings → Setup → API Keys → paste into Last.fm key → Save (a ✓ shows it works)

Lost it? Your keys are listed at last.fm/api/accounts.
